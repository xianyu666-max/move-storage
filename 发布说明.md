# Move Storage

Store Technical Machines in a machine block and teach any stored move to a party Pokémon at any time.

The screen reuses the layout of Cobblemon's TM Machine — party on the left, moves on the right, confirm at the bottom — but runs on its own menu and block, so the original TM Machine is untouched.

---

## Features

- **Store**: drop a TM into the import slot (or feed it with a hopper/pipe) and the move is recorded
- **Sorting**: every TM is listed — stored ones float to the top and stay clickable, unstored ones are greyed out
- **Learning**: pick a Pokémon → pick a move → click **Confirm**. Hovering a move updates the party list in real time with learnable / already known / not learnable
- **Materials**: follows Cobblemon's `infinite_tm_uses`
  - Free mode: material slots are locked, learn directly
  - Cost mode: needs the TM recipe materials or a spare TM of that move; if short, the confirm button greys out and the tooltip says exactly what is missing
- **Drops**: stored moves and stock counts drop with the block when broken, creative mode included
- **Automation**: hopper / item pipe input supported

## Crafting

```
D T D      D = Disc Shelf (cobblemon:disc_shelf)
D P D      T = TM Machine (cobblemon:tm_machine)
D D D      P = PC (cobblemon:pc)
```

## Commands

```
/movestorage store <move>   store a move
/movestorage list           list stored moves
/movestorage clear          clear all stored moves
```

## Requirements

- Minecraft 1.21.1, Fabric Loader ≥ 0.17.2
- Cobblemon 1.8.1
- Fabric API, Fabric Language Kotlin (bundled with Cobblemon)

# 招式存储器

把招式学习器（TM）存进机器，队伍里的宝可梦随时学习机器中已存储的招式。

界面沿用 Cobblemon 招式学习器机的布局——左侧队伍、右侧招式、底部确认，但使用独立的菜单与方块，原版 TM 机不受影响。

## 功能

- **存入**：把 TM 放进导入槽（或由漏斗/管道输入），招式即被记录
- **排序**：显示全部 TM，已存储的置顶高亮，未存储的置灰
- **学习**：选宝可梦 → 选招式 → 点「确认」；滑过招式时左侧实时显示能学习 / 已学会 / 无法学习
- **材料**：跟随 Cobblemon 的 `infinite_tm_uses`
  - 免费模式：材料槽锁定，直接学习
  - 消耗模式：需要配方材料或该招式的多余 TM 存量，不足时确认键置灰并提示缺什么
- **掉落**：破坏方块时，已存储的招式与存量随方块一起掉落（创造模式也掉落）
- **自动化**：支持漏斗 / 物品管道输入

## 合成

```
D T D      D = 光盘架 (cobblemon:disc_shelf)
D P D      T = 招式学习器机 (cobblemon:tm_machine)
D D D      P = PC 终端 (cobblemon:pc)
```

## 命令

```
/movestorage store <招式名>   存入招式
/movestorage list             查看已存储招式
/movestorage clear            清空
```
